# LibreSpydus for the desktop

A GPUI + gpui-kit app on the shared Rust core (`../core`, called directly, no UniFFI). The
contract is [`docs/desktop-app.md`](../docs/desktop-app.md); behaviour follows
[`docs/native-apps.md`](../docs/native-apps.md), ported from the iOS app.

## Build, run, test

```sh
cd desktop
cargo build                                   # debug build, ~1 min clean
cargo test                                    # unit + headless UI tests
cargo clippy --all-targets -- -D warnings
cargo fmt                                     # desktop/ only; never on core/
cargo run -- --data-dir /tmp/ls --library https://canning.spydus.com
cargo run --example public_search             # one public search with the ⏱ timing log
```

`desktop/target` is 4–5 GB; delete it when you're done with a worktree.

## Debug launch flags (`src/launch.rs`, debug builds only)

| Flag | |
|---|---|
| `--library <origin>` | select a library, skip the picker |
| `--demo` | demo mode, signed in as "Test Borrower" (`demo` / `demo` signs in again) |
| `--demo-refresh-fails` | demo account refreshes fail |
| `--reset` | delete saved files first (and, without `--data-dir`, this app's keychain items) |
| `--data-dir <dir>` | every file under `<dir>`, secrets in memory — **always use this when testing** |
| `--route <r>` | `home`, `search:<q>`, `results:<q>`, `detail:<url>`, `borrowed`, `borrowed:reservations`, `favourites`, `profile`, `libraries`, `login`, `card`, `gallery` (every component) |
| `--window <W>x<H>` | default 1280x820, at least 960x640 |
| `--evidence` | no activation or focus, window at a fixed position |
| `--screenshot <png>`, `--screenshot-after <s>` | render the window to a PNG after `<s>` s (default 6) and quit; needs `--features evidence` |

Debug builds print the timing log: `⏱ core …` per page the core loads (`src/timing.rs`) and
`⏱ app …` per `CoreBackend` call.

## Screenshots

The app renders its own window (GPUI `render_to_image`), which works over SSH where
`screencapture` doesn't:

```sh
desktop/scripts/screenshot.sh /tmp/librespydus-evidence/<task>/home.png [--wait 6] -- \
  --data-dir /tmp/librespydus-evidence/<task>/data --demo --library https://canning.spydus.com --route home
```

It builds with `--features evidence` and runs `--evidence --screenshot …`. Signed-in screens use
`--demo`; without it stay signed out (public pages only).

## Layout

| Path | |
|---|---|
| `src/app.rs`, `main.rs` | bootstrap: runtime, HTTP client, theme, menus, AppState, window, routes, screenshots |
| `src/runtime.rs` | the tokio runtime, `spawn_core`, `sleep`, and GPUI's `HttpClient` (core User-Agent) |
| `src/backend/` | `LibraryBackend`; `CoreBackend`; `DemoBackend` (+ `demo_catalogue`, iOS fixtures via `include_str!`); `FakeBackend` + `test_data` (debug builds, for tests) |
| `src/state/` | `AppState` and its stores: account (stale-while-revalidate), picks (account), local picks, settings, secrets, BookRef, Route/Section, UserFacingError/Loadable, formatting |
| `src/shell/` | `RootView` (onboarding, sidebar, toolbar, per-section stacks, dialog host, toasts), actions/menus/key bindings |
| `src/features/` | one module per feature; wave 1 has placeholders with the §5.6 entry points |
| `src/ui/` | shared components (§7.2) and the debug gallery |
| `src/theme.rs` | tokens → gpui-kit theme; a test checks every value against `design/tokens.json` |
| `src/copy.rs` | GENERATED by `design/scripts/gen_copy.py` — never edit |
| `src/platform/` | macOS-only window chrome |

## Working on a feature (wave 2)

- **AppState:** `AppState::global(cx)` → `Entity<AppState>`. Read with `.read(cx)`, change with
  `.update(cx, |state, cx| …)`. Long calls return `Task`s; await them in
  `cx.spawn(async move |this, cx| …)`. Feature-only operations go in an `impl AppState` block
  inside your feature directory (fields are `pub(crate)`).
- **Backend calls:** `state.backend()` → `Arc<dyn LibraryBackend>`; every async method returns a
  `'static` boxed future you can await from GPUI. Route errors through
  `state.report(&error, cx)` → `UserFacingError`.
- **Reloads:** compare `state.reload_key()` with the one your load used.
- **Navigation:** `push(Route, cx)`, `push_on(section, route, cx)`, `pop`, `select`,
  `open_search(query)` / `take_pending_search()`, `open_your_books(segment)` /
  `take_pending_segment()`.
- **Dialogs:** `window.open_dialog(cx, |dialog, _, _| ui::sheet_dialog(dialog).title(ui::dialog_title(…)).child(…))`;
  confirmations with `ui::ConfirmDialog`. Create `InputState`s before opening. Sign-in and the
  library picker open from `AppState::request_sign_in` / `request_library_picker` through
  `features::onboarding::open_sign_in` / `open_library_picker`.
- **Toasts:** `state.show_notice(message, NoticeTone::…, cx)` (the shell shows it), or
  `ui::toast::show(window, cx, …)`.
- **Copy:** every visible or spoken word from `crate::copy::Copy` (`Copy::Search::results(n)`).
  Note `use crate::copy::Copy;` shadows the `Copy` trait name in that file (derives still work).
- **Tests:** `tests/<feature>_*.rs`; `tests/support` builds an app on `FakeBackend`
  (`support::signed_out_app`), `#[gpui_kit::test]`, `gpui_kit::test::TestWindowExt`
  (`window.click("id", cx)`, `find("id").label()`). Elements are found only with `.id(..)` then
  `.test_support()`.
